# Паспорт инвестиционного тезиса — дополнительный материал к конкурсной заявке

[![microtest](https://github.com/SergeiUstiugov/thesis-passport/actions/workflows/microtest.yml/badge.svg)](https://github.com/SergeiUstiugov/thesis-passport/actions/workflows/microtest.yml)

Помощник кредитного аналитика на рынке рублёвых корпоративных облигаций. После
выхода новой отчётности он проверяет утверждение аналитика об изменении долговой
нагрузки эмитента: что подтверждено документами, что им противоречит и что
проверить нельзя.

Языковая модель только предлагает кандидатов в факты. Статус утверждения выносят
детерминированные правила. Инвестиционную интерпретацию система никогда не
подтверждает сама: это решение аналитика.

## Как запустить

Нужен Python 3.9 или новее, сторонние библиотеки не требуются.

```bash
git clone https://github.com/SergeiUstiugov/thesis-passport.git
cd thesis-passport
python check_rules.py
python mutation_check.py
```

Ожидаемый вывод:

```
Регрессионные кейсы: 13 из 13
Полный перебор: 256 комбинаций, расхождений с таблицей решений: 0, нарушений инвариантов: 0
ИТОГ: PASS
...
Мутантов: 6, выжило: 0
```

Тот же прогон автоматически выполняется в GitHub Actions при каждом изменении
(`.github/workflows/microtest.yml`), статус — на значке вверху.

## Что проверяет микротест

Одно утверждение: «новое нормализованное значение показателя меньше старого».
Проверка идёт на трёх уровнях.

1. **Регрессионные кейсы.** 13 случаев с ожидаемым статусом, заданным вручную.
2. **Полный перебор.** Все 256 комбинаций входов: пять флагов и отношение
   значений. Реализация `assign_status` сверяется с независимо записанной
   таблицей решений `DECISION_TABLE` и с инвариантами.
3. **Мутации.** Шесть намеренно испорченных версий правил. Тест должен
   провалиться на каждой из них.

Пример пользы перебора: ошибку порядка правил («противоречие опор проверяется
после сопоставимости») исходные 8 кейсов не обнаруживали. Её ловят
комбинационные кейсы и перебор.

### Таблица решений

Правила применяются по порядку, срабатывает первое подходящее.

| Правило | Условие | Статус |
| --- | --- | --- |
| R1 | Утверждение уровня «интерпретация» | `analyst_required` |
| R2 | Нет координат источника | `insufficient_data` |
| R3 | Нет одного из значений | `insufficient_data` |
| R4 | Несколько опор с разными значениями | `clarify` |
| R5 | Разный периметр (компания или группа) или разное определение показателя | `not_comparable` |
| R6 | Новое значение меньше старого | `confirmed` |
| R7 | Иначе | `contradicted` |

### Инварианты

Проверяются на всех 256 комбинациях:

- интерпретация всегда получает `analyst_required`;
- `confirmed` возможен только при наличии источника, обоих значений, одной опоры,
  сопоставимых данных и фактическом снижении;
- без координат источника нет вердикта `confirmed` или `contradicted`;
- статус всегда из допустимого набора, повторный вызов даёт тот же результат.

### Соответствие статусов заявке

| В коде | В заявке |
| --- | --- |
| `confirmed` | Подтверждено |
| `contradicted` | Противоречит источнику |
| `clarify` | Уточните: выбор за аналитиком |
| `not_comparable` | Несопоставимо |
| `insufficient_data` | Недостаточно данных |
| `analyst_required` | Требует суждения аналитика |

## Что этот материал доказывает и чего не доказывает

**Показывает:** правило назначения статуса ведёт себя так, как описано в заявке,
на всех комбинациях входов, а тест чувствителен к типичным ошибкам в правилах.

**Не показывает:**

- точность языковой модели, OCR, поиска или сверки координат;
- правильность выбора строки таблицы или понимания определения показателя;
- рыночный спрос, экономию времени аналитика или надёжность финансового продукта.

Флаги сопоставимости во входах заданы вручную. Числа 100, 80 и 120 условные и не
относятся к реальному эмитенту. Отрицательная и нулевая EBITDA не
рассматриваются. Доказательство корректности на Lean для этого правила не
выполнено; подход описан в заявке.

## Данные

В репозитории нет реальных данных эмитентов, внутренних материалов или выгрузок
коммерческих правовых баз. Все кейсы синтетические.
